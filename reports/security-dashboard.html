🌐 DAST — OWASP ZAP (requires running instance)
📋 DAST scan requires Docker daemon. The ZAP baseline scan runs automatically in GitHub Actions CI (.github/workflows/devsecops.yml).

To run locally:
docker run -d --name juice-shop -p 3000:3000 bkimminich/juice-shop:latest
docker run --rm -v $(pwd)/.zap:/zap/wrk ghcr.io/zaproxy/zaproxy:stable zap-baseline.py -t http://host.docker.internal:3000 -J zap-report.json -r zap-report.html

ZAP results are uploaded to DefectDojo (scan type: ZAP Scan) and the GitHub Security tab.
